BSB multilingual implementation rules

Go/Rust event filters are evaluated in configured alias sort order, first match wins. Missing/null filter accepts every operation; [] accepts none. Operation arrays, boolean maps, plugin lists and {enabled,plugins} entries are supported. Host appends an unfiltered local backend when none is configured. Place a catch-all after selective aliases. Malformed filters fail startup.
Registry implementation discovery returns only org/name/language/version summaries; fetch schemas/docs separately. Client installation rejects generated-name collisions before writing snapshots. .NET preserves UInt64 wire values; AnyVali C# 1.1.5 validates the full unsigned 64-bit range. Preserve exact integer results through SafeParse(...).Data or V.Parse instead of typed numeric methods returning double.

RUST HOST / CLIENT TOOLING (2026-09-06)
- Rust 1.95+; BSB owns main and lifecycle. Crates export register(&mut bsb::host::Registry)->bsb::Result<()>. Static Contract/Ordering plus factories; constructors never run during export. Custom configuration/event/observer factories are supported. register_observable factories take (validated_options, Host.cwd); built-in relative log and TLS certificate/key paths resolve against that application directory, preserving absolute paths.

- Full AnyVali 1.1.5 documents import once per event facade. Normalize SDK aliases only at schema nodes; preserve defaults, literals, definitions and metadata. Fresh reference parse contexts prevent cross-request contamination.
- bsb client install/sync/publish uses the shared Registry or private --target Vault. Source identity/version stays in .bsb/schemas; generated Rust modules go to src/bsbclients. Add pub mod bsbclients. Never handwrite shared-service clients.
- Optional<T>::Missing distinguishes omission from Present(None). Objects/arrays/maps/enums/references use typed Rust; complex structural shapes use Value plus full runtime validation. Generated client events() handles streams; specific(id) selects an instance. Pass incoming Observable through nested calls.
- Native configuration: file/env/Vault/Google ADC. Enabled plugins must target rust. Vault cache is encrypted and bound to endpoint/key/language. Invalid/auth/wrong-language responses never fall back to cached config. Environment override paths are explicitly allowlisted.
- Native events-default/Rabbit use matching durable queues, confirmed replies before ack, bounded retry/buffering and opaque stream IDs. Rust AsyncRead supports cancellation. Receivers consume through EOF and propagate errors. Streams do not resume across disconnects.
- Nine native observable backends; Pino/Winston names select equivalent Rust formats. TLS verification, bounded exporters and redaction-before-interpolation are required. Histogram ceiling: count/sum and one aggregate bucket. Runtime options are documented in rust/README.md.
- Seven examples in plugins/rust/native-examples use generated portable contracts; BSB links the crate. Todo's JSON file has one process owner and its unauthenticated HTTP example defaults to localhost.
- Release workflow creates a Rust .crate/CLI artifact and versioned runtime images. Image stages run non-root with CA certificates. No crates.io publish is configured.

BSB is the executable host. Applications are plugins loaded by BSB. Referencing BSB as a dependency does not start an application.

Registry identity is org/name + implementation language + version. The same version can exist independently in nodejs, csharp, python, go, java and rust. Normalize dotnet to csharp. Language metadata support does not imply that every native runtime is implemented.

GET /plugins/:org/:name/implementations discovers accessible variants. Pass ?language=csharp (or another source language) on details, versions, schema and documentation reads. /types/:language selects the output type language; its query language selects the source implementation. Unqualified legacy reads prefer Node when present. Clients must ask for --source-language when more than one accessible implementation exists.

Node: bsb client install org/service-name --source-language csharp --version 1.2.3
The generated client remains TypeScript. Schemas save source identity/version separately from the wire plugin target. Regeneration must preserve complete AnyVali documents, including definitions, defaults, wrappers and sensitive metadata. Do not replace shared services with handwritten native clients.

Vault chooses the host language on each deployment profile. An application can contain profiles for different languages. Existing profiles/catalog records default to nodejs. Native catalog entries and publishing credentials are scoped by language. Enabled plugins must match the host language; disabled service references may point at a remote implementation. A published deployment profile cannot change its host language. Create another profile for a different host.

Vault private uploads: run the native bsb plugin build and upload lib/schemas/{plugin-id}.plugin.json, not root bsb-plugin.json. Per-plugin manifests include id, language, version, category, packages[language] and configSchema. CI client publish --target uses package[language]. Vault stores one row per (pluginId, language, version) with the selected packageName; do not merge language variants into one package string. Native coordinates are npm names, NuGet IDs, Python distributions, Go import paths or Cargo crate names. The runtime package field resolves that language's coordinate. Vault distributes config/contracts, never installs executable packages; prepare native images first and link Go/Rust plugins at build time. Publisher credentials bind language/org/plugin/package/kind. Legacy data migrates to nodejs; java catalog metadata does not imply a Java host.

.NET contracts use AnyVali 1.1.5. BSB shares both BSB and AnyVali assemblies with dynamically loaded plugins. Declare static Metadata, ConfigSchema and EventSchemas on plugins. Use native AnyVali schemas or BSBTypes. Create generated clients in service constructors with the service Events context; BSB wires their backend before Init.

.NET config selection: BSB_CONFIG_PLUGIN=config-default|config-env|config-vault|config-vault-google. Optional BSB_CONFIG_PLUGIN_PACKAGE selects an external package. Config providers use the same lower camel case Vault settings as Node: vaultUrl, apiKeyId, apiSecret, timeoutMs, staleAllowedHours, cacheDir, allowInsecureHttp, googleAudience. Never log credentials.

Native Vault startup must reject wrong-language responses, auth failures, redirects and invalid schemas. Cache only validated responses, encrypted and bound to origin/key/language. Apply BSB_CONFIG_OVERRIDES in memory only, restricted to envOverridePaths returned by Vault. Cache formats are runtime-specific; do not share cache files between languages.

See dotnet/README.md for current implemented native features and CLI commands. Do not claim Go/Rust host support from registry enum values alone.

Go/Rust native hosts, tooling, backends and examples are implemented; see docs/native-go-rust-plan.md, go/README.md and rust/README.md. .NET RabbitMQ uses Node BSB 9 queue names and {trace:{t,s},args:[payload]} envelopes. Keep durable fire/RPC queues for missing listeners. Confirm replies before acknowledging requests; failed publishes must redeliver. Handlers must tolerate duplicate execution. Ten poison attempts dead-letter. Stream receivers register a callback and return an opaque ID; pass that ID to the sender. The old ReceiveStream/SendStream overloads without an ID only work locally.

.NET remote plugins: observable-opentelemetry (OTLP HTTP JSON), observable-axiom (dataset ingestion and OTLP traces), observable-zipkin (v2 traces), observable-graylog (GELF UDP/TCP/TLS/HTTP), observable-syslog (RFC 5424/3164 UDP/TCP/TLS). Use each native ConfigSchema; Node option layouts are not interchangeable. Buffers are bounded and non-durable. Keep TLS hostname/chain validation, no credential-bearing redirects, no retry of partial acknowledgements. Metrics have per-plugin namespaces; native recording overrides receive pluginName first.

.NET packages: BetterCorp.BSB SDK; BetterCorp.BSB.Cli tool, command bsb. bsb plugin pack <project.csproj> includes BSB metadata in NuGet. bsb plugin install <package> --version <exact-major.minor.patch> [--source <feed>] atomically installs .bsb/plugins/<package>/<version>; BSB_PLUGIN_DIR overrides the root. Configure logical plugin ID separately from NuGet package and assembly. Runtime-only images load prebuilt plugins; tooling requires an SDK build stage. Never construct application services during schema export.

Real broker integration passes all 20 Node/.NET/Python/Go/Rust RPC/trace/stream directions and crashed consumers. PostgreSQL migration CI passed at 017b1b9.

Vault shared application-profile publication validates each active deployment's effective configuration and host language. Disabled remote references retain their implementation language. Native AnyVali wrappers may use schema/inner and unions schemas/variants. Keep secret detection shared between server and browser. Sensitive collections and referenced schemas use write-only whole-value JSON replacement; omission preserves the existing value. Do not restore secrets by array index after a reorder.

Python config-default/env/Vault/VaultGoogle, events-default/Rabbit, and native observability plugins are implemented; see python/README.md for options. HOSTED CONTRACT DISCOVERY
- All five implemented CLIs accept bsb client install https://origin [--plugin org/name] [--source-language LANGUAGE] [--version VERSION] [--allow-insecure]. GET /.well-known/bsb expects {bsb:1,plugins:[{id,language,version,schema}]}; schema is a full event document or same-origin link. Multiple matches require an explicit selection. Preserve the wire pluginId; reject version mismatches.
- HTTPS origins only by default, no URL credentials/query/fragment/path, no redirects, no Registry token forwarding, 10-second/4-MiB request limits. Hosting discovery is explicit; no new listener or HTTP RPC transport is created. Snapshot source.url records the origin; generated filenames include its public SHA-256 prefix. Normal sync/generate stays offline. See docs/hosted-client-discovery.md for the authoritative format and fixture tests/fixtures/hosted-discovery.json.

Rust metric constructors counter/gauge/histogram return Result<Metric>; propagate registration errors. Identity is plugin/name; kind, description and unit must match existing definitions. Remote trace and span IDs must be correctly sized hexadecimal strings and individually nonzero.

Python synchronous stream sources must provide prompt, thread-safe close() that unblocks read. Cancellation closes the source and joins the reader; non-closable synchronous readers are rejected. Async read sources do not need close().

Go metric constructors reuse cumulative instruments by plugin/name; kind, description, unit and histogram boundaries must match on repeated registration. Conflicting definitions panic. .NET local transport borrows sender streams; late timeout completion and transport shutdown never dispose them.

Python JSON HTTP reads use a monotonic response deadline, incremental reads and active socket shutdown; timeout while reading an HTTP error body preserves its status with an empty diagnostic body. Platform DNS resolution and connection setup retain OS/stdlib timeout limitations.

AnyVali dependencies: npm/NuGet/Python/Rust 1.1.5; Go revision f98fa58c697c (the Go SDK is unchanged in v1.1.5). Go/Rust native contracts must put sensitive/writeonly flags inside metadata for header maps, telemetry tokens, Vault apiSecret and Rabbit credentials.password; Vault does not treat top-level sensitive flags as masking metadata. Logical clients prefer enabled mappings, then disabled remote mappings; true explicit aliases retain precedence.

Portable client objects: omitted required means no required fields. Go allow/passthrough objects use map[string]any; Rust preserves extra fields in a flattened map. Runtime schemas still validate payloads. Go imported event names reject control characters and event defaults cannot exceed 86400 seconds. Python lifecycle dependencies must resolve even when disabled; wheel entry points require an exact nonempty bsb.plugins group.

.NET generic int clients use long to preserve signed 64-bit integers. Returnable event timeout APIs use double seconds (finite, greater than zero, at most 86400); custom BSBEvents.EmitEventAndReturn overrides must use double. Generated defaults use invariant culture. Registry Request requires root-relative paths on its configured origin before sending credentials.

.NET declared Metadata.Name must match the requested plugin ID; only a single metadata-free implementation may use legacy fallback. TLS logging rejects clientKeyPath without clientCertificatePath before connecting. Go portable defaultTimeout distinguishes omission (five seconds) from explicit zero (invalid). Rust rotation removes partial gzip output after compression errors and preserves the uncompressed source.

Node generated RPC defaults also enforce the 86400-second portable maximum. .NET import/export rejects empty and control-character event names. Go rotation cleans partial gzip output; Go GELF converts nonstring/nonnumeric additional values to JSON strings. Rust GELF preserves configured facility and rejects normalized _id; Axiom metrics use recorded timestampNs. See docs/dependency-review.md for the Tokio 1.53.1 Socket assessment and unresolved evidence; a verified checksum is not a source-safety guarantee.

.NET numeric literal clients preserve signed/unsigned 64-bit integral values. Rust enabled plugin version pins must match their linked Contract.version before construction; omitted versions accept the linked implementation. Rust nonreturnable events must not declare outputSchema. Rabbit broadcast names must fit 255 UTF-8 bytes including the UUID suffix; Rust uniqueId must not contain the stream delimiter ||. Rust plugin manifests identify the current crate by lib.name when present, otherwise the normalized package name.

Rust GELF additionalFields accepts arbitrary JSON values, preserving strings/numbers and encoding other values as compact JSON strings. Go Rabbit also validates broadcast queue names after suffixing and rejects uniqueId containing || before connecting.

Node hosted contracts share Registry/Vault's schema-safety gate (10000 nodes, depth64, prototype keys rejected, pattern length1024 and safe-regex2 check). Vault editor catalogs must match the entry language for current/update schemas before masking configuration; unannotated legacy entries default to nodejs.
All five hosted clients require strict SemVer 2.0.0 for discovery versions and --version: reject leading zeroes in core/numeric prerelease identifiers, empty suffix identifiers and whitespace; permit build metadata such as +001. Go/Python/.NET Registry/package validators share their strict version check with hosted discovery. Keep tests aligned with tests/fixtures/semver-versions.json.
Go/Rust Rabbit uniqueId may be omitted or null for the hostname fallback. Rust local streams have separate registration and transfer deadlines; claiming a stream starts a fresh transfer timeout. .NET Rabbit disposal cancels active stream receivers and waits up to five seconds for their handlers before closing channels and connections; late publishes are rejected.
Go lifecycle dependencies reject unknown aliases/logical names and ignore configured disabled targets; local stream registration expiry calls its listener with a reader that reports the timeout. .NET Init/Run spans record hook failures and end even on synchronous throws. The .NET executable accepts development, production-debug and production for BSB_MODE (unset defaults to development), rejecting other values. Python bsb run generates an instance ID when BSB_APP_ID is absent and preserves an explicit value.

Python build contracts and manifests use the discovered module __version__, falling back to the project version. Python Rabbit attempts every configured endpoint with a 15-second timeout per attempt and validates complete broadcast queue names including the UUID suffix against 255 UTF-8 bytes. Python/.NET Rabbit reject uniqueId containing ||; .NET stream text chunks must fit 1 MiB after UTF-8 encoding, and its startup timeout budget includes both connections and every endpoint.

Vault deployment placeholder sync is limited to sibling profiles of the same language (missing language means nodejs). Generated disabled placeholders carry the source profile language; existing sibling entries remain intact.

Enabled Go service/events/observable version pins must match the linked contract before construction. Go local root spans have no parent; children preserve their actual parent. Python publishing uses each discovered manifest version for both request and contract (project fallback for legacy entries). Python/Rust local broadcasts deliver to all listeners after ordinary failures and report aggregated errors; Python task cancellation still propagates immediately.

Vault private uploads reject conflicting request/manifest/schema language declarations before catalog or publisher writes. dotnet normalizes to csharp; a request supplies language only when artifacts omit it, and fully unannotated uploads default to nodejs.

Go profile version fields must be strings when present; malformed pins are errors. Go Rabbit retries empty non-EOF source reads under the outstanding request and fails with io.ErrNoProgress after 100 attempts. Rust local root spans omit parentSpanId; nested/imported spans retain it. Rust local fire-and-forget/broadcast handlers have no RPC response deadline; returnable operations keep their deadline. .NET exact plugin pins require verifiable versioned resolution, including package-less definitions, and HTTP metric redaction runs before enqueueing.

Python/Rust default GELF HTTP URLs bracket IPv6 literal hosts and preserve explicit httpEndpoint overrides. Go service lifecycle contexts must not supply unrecorded parent span IDs. Go/Rust cumulative metric publication follows update order under concurrency so exported samples cannot regress from callback reordering. Rust coalesces pending cumulative snapshots to the latest value while an observer is publishing, keeping pending memory bounded.
